# MLOps

## Overview

MLOps infrastructure for the AI News Dashboard project.

## Features

- Code optimization
- CI/CD pipelines
- Documentation generation
- Performance monitoring
- Chaos engineering

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run optimizer
python agentic_code_optimizer.py

# Generate docs
python agentic_docs_generator.py
```

## Configuration

Edit `agentic_config.yaml` to customize settings.

## Scripts

- `agentic_code_optimizer.py` - Code optimization
- `headless_pipeline.py` - CI/CD automation
- `chaos_engineering.py` - Resilience testing
- `agentic_docs_generator.py` - Documentation generation
